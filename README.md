# Storage Estimator

## Purpose
This program converts a storage size entered in gigabytes (GB) into
megabytes (MB), kilobytes (KB), and bytes. It is a small Python project
for CS-117 Introduction to ICT, Lab 11.

## How to Run
1. Make sure Python 3 is installed.
2. Open a terminal in this folder.
3. Run:

       python storage_estimator.py

4. Enter a storage size in GB when prompted.

## Example
Input:

    Enter storage in GB: 1

Output:

    Storage in MB: 1,024.00
    Storage in KB: 1,048,576.00
    Storage in bytes: 1,073,741,824
